# プロジェクト概要

このアプリケーションは **Tauri** と **Next.js** を組み合わせて構築されたデスクトップアプリです。指定した議題から会話内容が逸れていないかをチェックし、逸れた場合には通知を行います。内部では Azure OpenAI Service を利用してテキストを解析します。

## 主な機能

- 会議の議題を設定し、その議題から会話が脱線していないかを検知
- 脱線を検出した際にデスクトップ通知を送信
- Next.js を用いたシンプルな入力 UI

## セットアップ

詳細なセットアップ手順はプロジェクトルートの [README.md](../README.md) を参照してください。ここでは概要のみを記載します。

1. Rust のツールチェーン管理に `rustup` を使用します。
2. Node.js のバージョン管理に `volta` を使用します。
3. 依存関係は `pnpm install --frozen-lockfile` でインストールします。
4. (オプション) `cargo install tauri-cli --version 1.6.0` を実行すると `cargo tauri` コマンドが利用可能になります。

必要な環境変数 (Azure OpenAI 関連) を `.env` ファイルなどで設定してください。

## 起動方法

```
pnpm tauri dev
# または
cargo tauri dev
```

## ディレクトリ構成

- `app/` - Next.js の `app` ディレクトリ。
- `components/` - 再利用可能な UI コンポーネント。
- `lib/` - 便利関数などのライブラリ。
- `src-tauri/` - Tauri (Rust) 側のコード。
